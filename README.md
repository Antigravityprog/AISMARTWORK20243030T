# Upload folder

Place your own approved portfolio files here (for example PDF, JPG, PNG, MP4, MP3). Then update the matching `outputUrl` in `../assets/data.js` with a relative path such as `uploads/project-report.pdf`.

Before publishing, confirm that you own the file or have permission to share it publicly. Do not upload private information, classmate data, copyrighted materials without permission, or credentials/secrets.
