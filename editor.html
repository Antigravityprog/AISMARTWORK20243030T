작업물 콘텐츠 편집기

코드를 직접 수정하지 않고 작업물 정보를 작성한 뒤, 공개 사이트에 반영할 데이터 파일을 내려받을 수 있습니다.

중요한 안내
이 도구는 현재 사용 중인 브라우저에 임시 저장하는 로컬 편집기입니다. 로그인·서버 저장·다른 기기 동기화 기능은 없습니다. 편집 후 data.js 내보내기를 눌러 공개 사이트의 assets/data.js를 교체하고, 결과물 파일도 uploads/에 넣은 뒤 GitHub에 Commit/Push해야 실제 사이트에 반영됩니다.
