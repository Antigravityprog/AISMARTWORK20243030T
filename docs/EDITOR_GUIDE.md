# 콘텐츠 편집기 사용 안내

## 실행
1. `public-site/editor.html`을 브라우저에서 엽니다.
2. 새 작업물을 만들거나 기존 작업물을 선택합니다.
3. 제목, 분류, 설명, 실제 사용 도구, 본인 역할, 실제 프롬프트, 제작 과정, 결과물 경로, 회고를 입력합니다.
4. `변경사항 저장`을 누릅니다.
5. `JSON 백업`으로 편집 데이터를 보관하고 `data.js 내보내기`로 공개 사이트용 파일을 생성합니다.
6. 공개 사이트 `public-site/assets/data.js`를 백업한 후 내보낸 파일로 교체합니다.
7. 결과물 파일을 `public-site/uploads/`에 넣고 입력한 경로가 실제 파일명과 일치하는지 확인합니다.
8. GitHub에 Commit/Push하고 Netlify 배포가 끝난 뒤 공개 URL에서 확인합니다.

## 현재 한계
- 이 편집기는 브라우저 로컬 저장소를 사용합니다. 서버 데이터베이스가 아니므로 다른 브라우저/기기와 동기화되지 않습니다.
- 편집기 자체는 관리자 인증을 제공하지 않습니다. 인터넷에 공개된 관리자 페이지로 사용하지 마세요.
- 파일 업로드 기능은 없습니다. 결과물은 별도로 `uploads/`에 넣고 GitHub에 올려야 합니다.
- 다중 기기 관리와 안전한 실제 업로드는 Supabase Auth + Database + Storage 연동 및 RLS/Storage 정책 검증 후 제공해야 합니다.
