# 이어서 작업하기

## 현재 기준
대학생 개인 포트폴리오 웹사이트. 디자인은 네이비·화이트·시안 중심이며, 대학 과제와 프로젝트 결과물을 제작 과정과 함께 보여주는 것이 핵심입니다.

## PDF 기반 게시 흐름
1. 웹사이트 파일과 코드를 준비한다.
2. GitHub에 저장소를 만들고 파일을 업로드한다.
3. 변경 사항을 Commit하고 Push한다.
4. Netlify에서 GitHub 저장소를 연결한다.
5. 빌드 명령과 배포 폴더를 지정하고 Deploy한다.
6. 공개 URL에서 첫 화면, 하위 경로, 새로고침을 확인한다.

## 포트폴리오 구성
- 영상
- 이미지
- 음악
- 보고서
- 카드뉴스
- AI 활용 가이드북
- 웹페이지

각 작업에는 결과물 외에 목적, 본인 역할, 사용한 생성형 AI/도구, 실제 프롬프트, 제작 과정, 결과, 회고를 함께 기록한다.

## 다음 개발 단계
1. `npm install`, `npm run typecheck`, `npm run build` 실행
2. 모든 라우트 직접 접속 및 반응형 확인
3. 실제 작업물 파일과 프롬프트 입력
4. 관리자 CRUD 및 파일 업로드 기능을 Supabase에 연결
5. GitHub 저장소와 Netlify 사이트를 사용자가 연결하고 배포 검증

검증하지 않은 기능을 완료했다고 표현하지 않는다. 실제 성과·수상·자격·개인정보는 사용자 확인 전 임의로 기재하지 않는다.
