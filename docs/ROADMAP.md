# 개인 포트폴리오 개발 로드맵

## 현재 목표
대학생이 만든 과제와 프로젝트를 결과물과 제작 과정으로 나누어 기록하고, GitHub와 Netlify를 통해 공개할 수 있는 개인 포트폴리오를 완성합니다.

## 단계별 계획
| 단계 | 범위 | 현재 상태 |
|---|---|---|
| M1 | 공개 사이트 기본 화면, 프로필, 프로젝트, 작업 유형 분류, 검색·필터, 과정 상세 | 정적 사이트 구현 및 구조 검사 완료. 시각 QA/React 빌드는 미완료 |
| M2 | GitHub 저장소와 Netlify 연결, 공개 URL 및 모바일 검수 | 설정 가이드 제공. 실제 계정 연결 및 배포 미완료 |
| M3 | 관리자 로그인, 콘텐츠 CRUD, 초안/게시 상태 관리 | Supabase 코드·SQL 초안 존재. 실제 연결 및 권한 검증 미완료 |
| M4 | 이미지·영상·음악·문서 파일 업로드 및 안전한 저장 | 미구현 |
| M5 | CSV/Excel/JSON/Markdown/ZIP 가져오기·내보내기 및 백업 | 미구현 |
| M6 | 접근성, SEO, 다국어, 성능, 개인정보·저작권 검수 | 일부 기본 구조만 존재. 검증 필요 |
| M7 | 운영 모니터링, 복구 절차, 최종 인수인계 | 미구현 |

## 다음 작업 우선순위
1. 실제 작업 결과물과 본인 프로필을 등록합니다.
2. GitHub 저장소에 업로드하고 Commit/Push합니다.
3. Netlify에 연결해 `public-site` 폴더를 공개 배포합니다.
4. 모바일·PC 화면, 검색, 필터, 상세 모달을 확인합니다.
5. 여러 기기에서 콘텐츠를 관리해야 하는 경우 Supabase Auth/Database/Storage를 연결합니다.
6. 관리자 CRUD와 파일 업로드 권한을 별도 계정으로 테스트합니다.
7. 백업·복구 및 최종 공개 검수를 진행합니다.

## 운영 원칙
- 확인되지 않은 프로젝트 성과, 점수, 수상, 자격을 입력하지 않습니다.
- 개인 연락처와 프로필은 공개 범위를 직접 결정합니다.
- 저작권과 공개 권한이 확인된 파일만 업로드합니다.
- 구현, 실행 검증, 외부 서비스 연결, 실제 배포 상태를 서로 구분해 기록합니다.
