# 프로젝트 상태 — 대학생 개인 포트폴리오

기준일: 2026-11-25

## 프로젝트 목적
대학생이 수업·개인 학습·프로젝트에서 만든 결과물을 유형별로 공개하고, 결과물과 함께 제작 목적, 본인 역할, 사용 도구, 실제 프롬프트, 작업 단계, 회고를 기록하는 개인 포트폴리오 웹사이트.

## 이번 배치에서 구현한 내용
- 기존 React + TypeScript + Vite 프로젝트를 기준으로 작업 지속
- PDF의 GitHub → Netlify 배포 흐름을 배포 안내 기준으로 채택
- 개인 포트폴리오 전용 `/portfolio` 페이지 추가
- 작업 유형 분류: 영상, 이미지, 음악, 보고서, 카드뉴스, AI 가이드북, 웹페이지
- 작업 카드별 상세 모달: 사용 도구, 제작 과정, 프롬프트 기록란, 회고, 프로젝트 상세 링크
- 검색 및 카테고리 필터
- 기존 프로젝트 목록을 학생 과제/학습 프로젝트 중심으로 정리
- 프로필·활동·수상·갤러리·자료실에서 검증되지 않은 이력/파일/성과를 제거하거나 입력 대기 상태로 변경
- 네이비·화이트·시안 디자인 및 기존 반응형 레이아웃 유지
- Navigation/Footer에 포트폴리오 전용 메뉴 추가

## 콘텐츠 정확성 원칙
- 예시 콘텐츠는 실제 최종 산출물 또는 검증된 이력으로 오인되지 않도록 DEMO/기록 예시로 표시
- 확인되지 않은 수치, 수상, 자격, 소속, 참여 기간, 다운로드 파일을 만들어내지 않음
- 이름, 학교, 전공, 학년, 연락처는 소유자가 공개 여부를 결정하고 직접 입력
- 프롬프트는 실제 사용한 원문을 입력하도록 기록란을 제공하며 임의로 원문을 만들어 넣지 않음

## 구현 상태
| 영역 | 상태 | 비고 |
|---|---|---|
| 홈 / 소개 / 프로젝트 목록·상세 | 구현됨, 빌드 검증 대기 | 콘텐츠는 예시/초안 포함 |
| 작업 포트폴리오 `/portfolio` | 구현됨, 빌드 검증 대기 | 7개 유형, 검색, 필터, 과정 상세 |
| 자료실 / 갤러리 / 수상 | 화면 구현, 실제 자료 미등록 | 실제 파일과 증빙 입력 필요 |
| 활동 / 역량 / 저널 | 기본 화면 구현 | 사용자 사실 정보 검토 필요 |
| 관리자 인증 / Supabase | 기존 코드 및 SQL 초안 | 실서비스 연결·권한 테스트 미완료 |
| 실제 파일 업로드 및 영구 저장 | 미완료 | Storage/DB 연동 필요 |
| GitHub / Netlify 실제 배포 | 미완료 | 사용자 계정 연결 및 배포 검증 필요 |
